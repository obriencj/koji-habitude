# Release 0.9.1

*Not Yet Released*

Hit that tracker for ideas and issues! Now is the best time to provide
feedback.


## Fixes

- Line provenance was breaking the TagModel's groups field. Added filtering
  prior to validation.

- Targets which omitted their dest tag name were stuck always showing as
  needing changes. Correctly considers the dest tag name to implicitly be the
  target name if not set.

- Skip non-file entries when traversing for yaml data. Some editors copy a
  new non-file with the same suffix when a file is opened for editing.


## Features

- Enables logging in templates via the _logger binding. Stores the original
  render data in the _data binding. The 'do' tag is enabled in Jinja2, so it's
  possible to emit logging messages mid template expansion now.

- Improved the 'multi' template's trace handling, providing clearer expansion
  provenance.
